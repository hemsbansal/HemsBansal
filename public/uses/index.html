Uses

What I reach for when I build mobile apps and voice AI. Updated Oct 2026.

Building apps

  • React NativemobileOne codebase for iOS and Android, with native modules when I need to go deeper.
  • TypeScripteverywhereOn the phone, on the server and on the web.
  • Zustand and ReduxstateZustand for small and simple, Redux when a team needs structure.
  • React and Next.jswebFor dashboards and the occasional website.

Voice and AI

  • OpenAI Realtime APIvoiceSpeech in and speech out over one connection. The biggest single latency win I've had.
  • ElevenLabs and PlayHTvoicesFor agents that should not sound like a robot.
  • WebSocketsreal-timeFor anything that streams.

Backend

  • Node.js with NestJS or ExpressAPIsNestJS for bigger services, Express for small ones.
  • PostgreSQL and RedisdataPostgres for almost everything, Redis for speed.
  • AWS, Docker and GitHub ActionsshippingBuild, test and deploy without thinking about it.

Debugging

  • Android Studio and XcodenativeWhere the real answers usually are.
  • FlipperinspectNetwork, logs and layout on a running app.
  • Firebase CrashlyticsproductionThe first place I look when users say "it crashed".
  • PostmanAPIsFor poking at endpoints before the app does.
  • Real phonestestingSimulators don't have Bluetooth headsets or bad Wi-Fi.
